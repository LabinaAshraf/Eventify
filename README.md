# Eventify 🎟️

A modern and responsive event discovery website built with HTML, CSS, and JavaScript.

## 🌐 Live Demo

[Open Eventify Website](https://labinaashraf.github.io/Eventify/)

## ✨ Features

- 🔍 Event search functionality
- 🏷️ Category filtering
- 🎟️ Event registration popup
- 🌙 Dark mode
- 📱 Responsive design
- 👩‍💻 Developer profile section
- 💼 LinkedIn and GitHub links
- 📩 Contact form
- 🖼️ Event images
- ⚡ Interactive JavaScript functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
